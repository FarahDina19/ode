🌍 Apa itu Differential Equation?

💡 Contoh dalam Kehidupan Sebenar:

Bayangkan anda memanaskan secawan kopi panas dalam bilik sejuk.

Suhu kopi akan menurun dengan kadar yang bergantung kepada perbezaan suhu antara kopi dan bilik.

Kadar perubahan suhu (berapa cepat sejuk) = fungsi perbezaan suhu

Ini adalah contoh differential equation dalam kehidupan harian!

🔍 Definisi Mudah:

Differential equation adalah persamaan yang mengandungi derivative (kadar perubahan).

First Order bermaksud derivative tertinggi adalah dy/dx (first derivative sahaja).

Fungsi y
→
Derivative dy/dx
→
Hubungan dengan x dan y

Matlamat kita: Cari fungsi asal y(x) dari persamaan yang melibatkan dy/dx

📐 Formula & Kaedah

General Form:

dy dx = f(x) · g(y)
dy dx = derivative (kadar perubahan)
f(x) = fungsi yang mengandungi x sahaja
g(y) = fungsi yang mengandungi y sahaja

🔧 Langkah-langkah Separation of Variables:

1. Pisahkan pembolehubah
→
2. Integrate kedua-dua belah
→
3. Apply initial condition & tulis jawapan

Method Template:

dy dx = f(x) · g(y)
⬇️ Pisahkan
1 g(y) dy = f(x) dx
⬇️ Integrate
∫ 1 g(y) dy = ∫ f(x) dx
⬇️ Hasil
G(y) = F(x) + C
Jawapan akhir dalam bentuk implicit (contoh: ln(y) = ...)

Contoh 2: dy dx = y x , y(1) = 2

🎨 Visualisasi

Given: dy dx = y x
Initial: y(1) = 2
Step 1: Pisahkan
1 y dy = 1 x dx
Step 2: Integrate
ln|y| = ln|x| + C
Step 3: Cari C
ln(2) = ln(1) + C
C = ln(2)
Jawapan:
ln(y) = ln(x) + ln(2)

📝 Penyelesaian Symbolic

dy dx = y x
1 y dy = 1 x dx
∫ 1 y dy = ∫ 1 x dx
ln|y| = ln|x| + C
y(1) = 2: ln(2) = ln(1) + C
ln(1) = 0, jadi C = ln(2)
Jawapan Akhir: ln(y) = ln(x) + ln(2)

Common Integrals untuk Separation of Variables:

Fungsi y:

∫ 1 y dy = ln|y| + C
∫y dy = y² 2 + C
∫y² dy = y³ 3 + C
∫√y dy = 2 3 y^(3/2) + C

Fungsi x:

∫x dx = x² 2 + C
∫x² dx = x³ 3 + C
∫ 1 x dx = ln|x| + C
∫e^x dx = e^x + C

Bentuk-bentuk Biasa:

Type 1: dy dx = f(x) → y = ∫f(x) dx
Type 2: dy dx = g(y) → ∫ 1 g(y) dy = x + C
Type 3: dy dx = f(x)g(y) → ∫ 1 g(y) dy = ∫f(x) dx

💡 Tips & Kesilapan Biasa

⚠️ Kesilapan Yang Selalu Berlaku:

  • Lupa pisahkan pembolehubah dengan betul
    Salah: dy = 2xy dx
    Betul: (1/y) dy = 2x dx
  • Lupa absolute value dalam ln
    ∫(1/y) dy = ln|y|, bukan ln(y)
  • Lupa tambah constant C
    Mesti ada +C bila integrate!
  • Salah apply initial condition
    Substitute nilai x dan y yang betul

💡 Tips Untuk Ingat:

  • Periksa sama ada boleh pisah
    Mesti boleh tulis sebagai f(x)·g(y)
  • Visualkan proses pisah pembolehubah
    Semua y ke kiri, semua x ke kanan
  • Integrate dengan teliti
    Gunakan formula integral yang betul
  • Semak jawapan
    Differentiate balik untuk verify!
  • Practice banyak-banyak
    Semakin banyak practice, semakin mahir!
